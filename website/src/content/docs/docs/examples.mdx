Every example is a Bazel package with a shared `core` library and one target per backend. Replace
`desktop-awt` with another target name to run an example on a different platform.

## Core APIs

| Example | Shows | Targets |
| --- | --- | --- |
| `//examples/hello-canvas` | Canvas drawing, typed drawables and audio, animation, pointer input, text boxes | `desktop-awt`, `desktop-lwjgl`, `html5`, `html5-opengl`, `desktop-native` |
| `//examples/hello-scalagl` | Raw OpenGL: shaders, buffers, textures, orbit camera | `desktop-lwjgl`, `html5`, `desktop-native` |
| `//examples/snake` | A complete small game with safe-area layout and Android wiring | `desktop-awt`, `desktop-awt-safe-area`, `html5`, `desktop-native`, `android-*` |
| `//examples/live-config` | Hot reload of an image, a level, and settings in development builds; none of it in release builds | `html5-dev`, `desktop-dev`, `html5`, `desktop`, `headless-test` |

## GameObject engine

| Example | Shows | Targets |
| --- | --- | --- |
| `//engines/gameobject/examples/asteroids` | Typed composition, `Updatable`, systems, scenes, `TextOverlay` | `desktop-lwjgl`, `html5`, `desktop-native` |
| `//examples/hello-atlas` | `sgl_texture_atlas`, sprites and tilemaps from one atlas page | `desktop-lwjgl`, `html5`, `desktop-native` |
| `//engines/gameobject/examples/solar-system` | 3D: spatial hierarchy, meshes, materials, orbit camera | `desktop-lwjgl`, `html5`, `desktop-native` |
| `//engines/gameobject/examples/headless-control` | Driving a game from a test with the headless backend | `headless-control-integration-test` |

## Screen2D engine

| Example | Shows | Targets |
| --- | --- | --- |
| `//engines/screen2d/examples/platformer` | Screens with a map imported by `sgl_tiled_import` | `desktop-awt`, `desktop-native` |
| `//engines/screen2d/examples/board` | `Viewport` scaling and camera movement | `desktop-awt`, `html5` |
| `//engines/screen2d/examples/menu` | scene2d menus | `desktop-awt`, `html5`, `desktop-native` |

```bash
bazel run //engines/gameobject/examples/asteroids:desktop-lwjgl
bazel run //engines/gameobject/examples/asteroids:html5    # http://localhost:8080
bazel build //examples/... //engines/...
```
