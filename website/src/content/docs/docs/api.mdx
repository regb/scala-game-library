<Aside type="tip" title="Where to start reading">
`Application`, `CanvasProvider`, `OpenGLProvider`, `AudioProvider`, `Input`, and `util/Loader.scala`
cover most of the core. For the GameObject engine, start with `Core.scala`, `typed/TypedObject.scala`,
and `runtime/Runtime.scala`.
</Aside>
