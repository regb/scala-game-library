## Building Scaladoc locally

Generate the same HTML reference directly from the repository with Bazel:

```bash
bazel build //website:scaladoc
```

The output is written to `bazel-bin/website/scaladoc/index.html`.

<Aside type="tip" title="Where to start reading">
Start with [`Application`](/api/sgl/Application.html), [`CanvasProvider`](/api/sgl/CanvasProvider.html), [`OpenGLProvider`](/api/sgl/OpenGLProvider.html), [`AudioProvider`](/api/sgl/AudioProvider.html), [`Input`](/api/sgl/Input$.html), and [`Loader`](/api/sgl/util/Loader.html) for the core. For the GameObject engine, browse [`sgl.engine.gameobject`](/api/sgl/engine/gameobject.html).
</Aside>
