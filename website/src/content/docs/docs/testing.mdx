## Frame capture

Every application backend implements `FrameCaptureProvider`. A request completes after the next
frame that starts after the request. It returns tightly packed RGBA8 pixels, starting from the top
left:

```scala
captureNextFrame().foreach { frame =>
  println(s"captured ${frame.width}x${frame.height}")
}
```

The core API returns pixels and does not choose a file format or storage. On the desktop JVM,
`sgl.desktop.DesktopFrameIO.writePng(frame, path)` encodes a capture as PNG.

The AWT and LWJGL examples in the SGL repository include an opt-in screenshot mixin, which captures after 30 warm-up
frames:

```bash
SGL_SCREENSHOT_PATH=/tmp/frame.png bazel run //examples/hello-canvas:desktop-awt
SGL_SCREENSHOT_PATH=/tmp/frame.png bazel run //examples/hello-scalagl:desktop-lwjgl
```

Set `SGL_SCREENSHOT_DELAY_FRAMES` to change the number of warm-up frames.

## Headless OpenGL

`@sgl//backends/headless-opengl:sgl-headless-opengl` renders to a Mesa surfaceless EGL pbuffer. It
needs no X11, no Wayland, and no GPU. Mix `HeadlessOpenGLApp` into an application, then step the
game and send it input yourself:

```scala
app.start()
try {
  app.Controller.keyDown(Input.Keys.Right)
  app.step(1.0 / 60.0)
  app.Controller.keyUp(Input.Keys.Right)
  app.step(1.0 / 60.0)
  val frame = app.captureNextFrame()
  app.step(1.0 / 60.0)          // the capture completes during this frame
} finally app.stop()
```

`Controller` accepts keyboard, mouse, touch, scroll, and system-action events from any thread.
`step` dispatches queued events on the OpenGL thread, then advances the game by one frame.

On Linux, set `EGL_PLATFORM=surfaceless` and `LIBGL_ALWAYS_SOFTWARE=1` to force Mesa's software
renderer. The backend's own Bazel test also clears `DISPLAY` and `WAYLAND_DISPLAY`, and checks that
the OpenGL renderer is llvmpipe.

In the SGL repository, `//engines/gameobject/examples/headless-control` drives a GameObject game
this way in an integration test. See [AI coding agents](/docs/ai-agents/) for how headless execution and frame
capture form an end-to-end verification loop for AI-generated game code.

## Test your game

Labels on this page are for a game in its own module, where SGL is `@sgl`. Inside the SGL
repository, drop the `@sgl` prefix. `scala_test` needs the `scala_deps.scalatest()` line from
[Installation](/docs/installation/).

```python title="BUILD"
load("@rules_scala//scala:scala.bzl", "scala_test")

scala_test(
    name = "game_test",
    size = "small",
    srcs = ["GameTest.scala"],
    env = {
        "DISPLAY": "",
        "EGL_PLATFORM": "surfaceless",
        "LIBGL_ALWAYS_SOFTWARE": "1",
        "WAYLAND_DISPLAY": "",
    },
    deps = [
        ":core",
        "@sgl//backends/desktop-jvm-shared",
        "@sgl//backends/headless-opengl:sgl-headless-opengl",
        "@sgl//core:sgl-core",
        "@sgl//engines:sgl-gameobject",
    ],
)
```

A test cannot reach into the world of a running game from the outside. Override `configure` to add
a probe: a system that runs after the game's own systems in each frame and copies the state the
test needs.

```scala title="GameTest.scala"
import org.scalatest.funsuite.AnyFunSuite
import sgl.{DesktopSystemProvider, Input}
import sgl.engine.gameobject._
import sgl.headless.opengl.HeadlessOpenGLApp
import sgl.geometry.Vec2
import sgl.util.NoLoggingProvider

class GameTest extends AnyFunSuite {

  final class TestApp extends HeadlessOpenGLApp with Game with DesktopSystemProvider with NoLoggingProvider {
    override val frameDimension: (Int, Int) = (800, 600)

    // Written on the OpenGL thread, read by the test.
    @volatile var player: Option[Vec2] = None

    override def configure(builder: GameBuilder): Unit = {
      super.configure(builder)
      builder.addSystem(Stage.PostUpdate, GameSystem("test-probe") {
        val world = summon[GameContext].world
        player = world.index[Player].toVector.headOption.map(_.position)
      })
    }
  }

  test("holding Right moves the player right") {
    val app = new TestApp
    app.start()
    try {
      // An AsyncScene appears a few frames after the start.
      var waited = 0
      while(app.player.isEmpty && waited < 300) { app.step(1.0 / 60.0); waited += 1 }
      val start = app.player.getOrElse(fail("the scene did not appear"))
      app.Controller.keyDown(Input.Keys.Right)
      for(_ <- 0 until 30) app.step(1.0 / 60.0)
      app.Controller.keyUp(Input.Keys.Right)
      assert(app.player.exists(_.x > start.x))
    } finally app.stop()
  }
}
```

`Game` is your game's main trait, and `Player` is a component with a `position`. Copy values such as
`Vec2` in the probe, rather than keeping components, so the test compares states of different frames.
The [starter project](https://github.com/regb/sgl-starter-project) has a complete suite that also
checks the pixels of a captured frame.

## Writing reliable headless tests

A few habits keep headless tests fast, deterministic, and genuinely useful for catching gameplay and visual bugs:

- **Settle `AsyncScene` before frame 0.** An `AsyncScene` finishes `preload` asynchronously before `load(...)` populates the world. Keep any readiness flag unset until `load(...)` runs, and loop `app.step(1.0 / 60.0)` until the scene is ready before capturing initial screenshots or sending input—otherwise frame 0 is blank.
- **Drive simulation from virtual time.** Use `context.dt`, `ElapsedTime`, or `FixedUpdate` instead of `System.nanoTime()` or `System.currentTimeMillis()`. That lets `app.step(1.0 / 60.0)` fast-forward minutes of gameplay deterministically in milliseconds.
- **Cover negative paths, endings, and persistence.** Test rejected actions, full win/game-over transitions (including frozen input after terminal states), and clean restarts. When testing `FileSaveComponent`, verify reload in a second fresh process so singleton state (such as `sgl.Input`) cannot mask save/load bugs.
- **Inspect captured PNGs visually.** Pixel spot-checks catch missing renders, while opening saved PNGs catches HUD overlap, clipped sprites, and camera framing issues.
- **Restricted sandboxes.** In environments that block loopback sockets or network metrics, pass `--batch --noexperimental_collect_system_network_usage` to Bazel:
  ```bash
  DISPLAY="" WAYLAND_DISPLAY="" EGL_PLATFORM=surfaceless LIBGL_ALWAYS_SOFTWARE=1 \
    bazel --batch --noexperimental_collect_system_network_usage test //...
  ```

## Unit tests

Engine and core logic can be tested without a backend. The GameObject engine's own tests in
`engines/gameobject/src/test`, in the SGL repository, build worlds, attach components, and run schedules directly. Run all
the tests of your project with:

```bash
bazel test //...
```
