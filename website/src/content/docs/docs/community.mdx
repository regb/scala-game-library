## Contributing

Pull requests should build and pass all tests, and BUILD files should be formatted:

```bash
bazel build //...
bazel test //...
bazel run @buildifier_prebuilt//:buildifier -- -mode=check -lint=warn -r .
```

Explain the motivation for API changes in the pull request. Many design decisions are documented in
comments at the top of the relevant source files.

## Documentation

This site is in `website/` and uses [Astro Starlight](https://starlight.astro.build/). Every page
has an edit link at the bottom. To preview changes locally:

```bash
cd website
pnpm install
pnpm dev
```
