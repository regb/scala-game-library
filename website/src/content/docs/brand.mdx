  <section class="page-section">
    <h2>Naming, typography &amp; usage rules</h2>
    <div class="callout-grid">
      <article class="callout">
        <h3>Naming</h3>
        <ul>
          <li>Write <strong>SGL</strong> in all caps in prose (never <code>sgl</code> or <code>S.G.L.</code>).</li>
          <li>Use <strong>Scala Game Library</strong> in title case on first formal mention or in titles (e.g. <em>SGL — Scala Game Library</em>).</li>
          <li>Refer to the website as <code>libsgl.com</code> and Bazel module identifiers (<code>sgl.bzl</code>, <code>@sgl</code>) in monospace.</li>
        </ul>
      </article>
      <article class="callout">
        <h3>Typography</h3>
        <ul>
          <li><strong>Display headings &amp; wordmark:</strong> Space Grotesk (600 / 700).</li>
          <li><strong>Body &amp; documentation UI:</strong> Inter (400 / 500 / 600).</li>
          <li><strong>Code &amp; CLI:</strong> JetBrains Mono (400 / 500).</li>
        </ul>
      </article>
      <article class="callout">
        <h3>Logo usage</h3>
        <ul>
          <li>Keep clear space of at least <strong>0.25×</strong> the mark height on all sides.</li>
          <li>Minimum digital size: <strong>24 px</strong> for the icon (16 px favicon).</li>
          <li>Do not stretch, rotate, swap ribbon order, add drop shadows, or place the bare mark over busy artwork without a solid backing pill.</li>
        </ul>
      </article>
